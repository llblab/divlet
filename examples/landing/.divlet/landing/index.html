  • One project fileproject.divlet holds every frame, component, token and the CSS that is shared.
  • Real HTMLWhat you see is the page: real markup rendered from the validated project, not a screenshot or a hidden app.
  • Tailwind firstClasses, not bespoke CSS. The inspector explains a class, suggests one, or sets a declaration for you.
  • Undo means undoEvery change is logged with who made it, what it touched, and reverts as one step.

How a change lands

  1. 1
    You point at something

    Select a frame or an element on the board and say what you want — “tighter hero, warmer card”.

  2. 2
    The agent reads, then edits

    It reads the frame model, then changes structure with one operation and classes, text or components with another.

  3. 3
    The board validates and shows it

    The change is checked against the format, versioned, rendered, saved and logged. Nothing half-applied, nothing lost.

  4. 4
    You keep or undo it

    Undo reverts a whole accepted edit, including a drag you made yourself a minute ago.

Other formats come in, nothing gets locked in

HTML pages come in through the native core; foreign formats such as PEN use importer plugins. Explicitly opening a source creates or reuses a sibling project without rewriting it. Pages exported back out are plain, readable HTML.

Get divlet

One npm package, @divlet/core, supplies the runtime and plugins, with browser assets in @divlet/web and CLI/MCP/Pi adapters. Requires Node.js 22.19 or later. Version 0.0.3 is an early release candidate; the native project format remains a pre-freeze draft.

Open a local board

No agent host required. Run the divlet command from the package of the same name.

npx -y @divlet/cli ./my-project

From Pi

Install @divlet/pi, the Pi adapter that depends on divlet, once both are published.

pi install npm:@divlet/pi

Then run /divlet ./my-project in Pi for the board, tools and bundled skill.

From anything that speaks MCP

Configure your MCP host to start this stdio server. divlet-mcp is a command inside divlet, not a separate package. No Pi required.

npx -y @divlet/mcp --cwd ./my-project

Local first: the board binds to loopback, the project is a file in your folder, and nothing is uploaded. Frames, components and shared tokens live in project.divlet; generated pages live under .divlet/ beside it.
