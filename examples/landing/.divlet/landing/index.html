A layout board for coding agents

Design in the browser.
Change it in conversation.

divlet gives your agent a board of real web pages. Point at what should change; the agent edits through validated tools, and you watch every accepted change land — versioned, logged and one Undo away.

Get startedTry it without installing

This page is a divlet project too: one frame of plain HTML and CSS.

  • Real pagesEvery artboard is a live page of HTML, SVG and CSS. Resize it to check the phone layout; what you see is what ships.
  • Point, then askSelect an element and ask. The agent reads the same selection, frame and measured layout you are looking at.
  • Validated editsEach change names the version it was made against. Stale or invalid edits are refused, never half-applied, and History records who changed what.
  • One file you ownproject.divlet holds frames, components, tokens and CSS. Generated pages are plain HTML you can host anywhere.

How a change lands

  1. 1
    You point

    Select a frame or an element and say what you want: “tighter hero, warmer card”.

  2. 2
    The agent reads, then edits

    It reads the frame and its version, then changes structure, text, styles or components by stable IDs.

  3. 3
    The board checks and shows it

    The change is validated, rendered and saved as one step, or refused with a reason the agent can act on.

  4. 4
    You keep it or undo it

    Undo reverts the whole accepted edit, whether the agent made it or you dragged something a minute ago.

Let your agent edit it

The site is its own MCP provider. Register it by URL in Claude Code, an editor or any MCP host: the tools run in a browser page that divlet-mcp opens, not on your machine.

npx -y @divlet/mcp --connect https://llblab.github.io/divlet/

Use it on your own projects

Requires Node.js 22.19 or later. The board binds to loopback and your project stays a file in your folder; nothing is uploaded.

A board on your machine

Open a folder; an empty one gets a starter project, an existing one opens as it is.

npx -y @divlet/cli ./my-project

Your MCP agent

Install the workflow skill once, then register the server. The agent opens the board when it needs one.

npx skills add llblab/divlet --skill divlet --global
npx -y @divlet/mcp --cwd ./my-project

Pi

The extension brings the tools, the skill and the Agent conversation to the board.

pi install npm:@divlet/pi

Then run /divlet in your workspace.

Version 0.0.3 is an early release; the native project format remains a pre-freeze draft, so keep backups of projects you care about.

Seven tools, one contract

Pi, MCP and the browser board run the same tool definitions, validation and refusal codes. The skill teaches the loop: read, edit with the version you read, verify what rendered.

  • open_divletOpen a project and its local board.
  • read_divletFrames, nodes, components, the user's selection, measured layout and history.
  • patch_divletChange a frame or the project by stable IDs, at a known version.
  • edit_divletInsert, move, wrap, duplicate, rename or remove elements.
  • frame_divletCreate, duplicate or delete frames.
  • undo_divletUndo or redo the latest change.
  • mark_divletShow the user where the agent is about to work.

Bring pages in, take plain HTML out

Static HTML pages open through the native importer, Pencil files convert through a plugin, and Markdown folders become routed sites. A source is never rewritten: divlet creates a sibling .divlet once. What comes out is ordinary HTML and CSS.

.html static pages.pen PencilMarkdown sites.divlet native

Honest boundaries

  • Layouts, not applications. HTML, SVG and CSS; no scripts or event handlers.
  • Generated pages are output. Hand edits there are reported and preserved, not imported back.
  • The browser board is a copy. It edits this site's project; images, fonts and utility classes need the local board.
