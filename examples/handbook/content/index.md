Welcome to **Divlet Fieldnotes** — a tiny documentation site composed from a reusable layout and a folder of Markdown files.

The agent can shape the page shell while other agents write individual chapters. Save a source file and the open site follows the accepted update.

## Three pieces, one site

| Piece | What it controls |
| --- | --- |
| Template | Typography, navigation, spacing and responsive layout |
| Markdown | The words, examples and images on each page |
| File tree | Routes and navigation structure |

## Follow the thread

Start with [the guide](./guide/index.md), or jump straight to [your first route](./guide/start.md#your-first-route).
